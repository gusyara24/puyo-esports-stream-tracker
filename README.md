# puyo-esports-stream-tracker

ぷよぷよeスポーツの配信向け、レート記録ツールです（非公式）。
OBS に映しているゲーム画面からレートと戦績を読み取って記録し、配信画面に表示します。
配信しなくても、OBS とつなぐだけで記録して、あとから振り返れます。

## ダウンロード

[Releases](../../releases/latest) から、最新の zip をダウンロードしてください（「Source code」は使いません）。
各版で変わったところも、Releases に書いてあります。

## 使い方

zip を解凍します。
中の「起動.bat」をダブルクリックします。
ブラウザに「はじめに」の画面が開くので、案内に沿って準備します。
くわしい手順は、zip の中の「使い方ガイド.html」に書いてあります（起動する前でも読めます）。

## 動かすのに必要なもの

- Windows 10 / 11（64ビット）。Mac・Linux では動きません。
- OBS Studio 28 以上（このツールと同じパソコンで動かしてください）
- Node.js などのインストールは不要です（zip に同梱しています）

ゲーム画面は 1920x1080 で取り込んでください。解像度が低い場合や、OBS で色の補正をかけている場合は、数字を読めないことがあります。

## 更新するとき

起動.bat の黒い窓を閉じてから、新しい zip を今のフォルダに上書きで解凍してください。
記録と設定（data フォルダ）は消えません。

## 安心して使うために

- このツールは、あなたのパソコンの中だけで動きます。
- OBS のパスワードと試合の記録は、インターネットにも作者にも送りません（YouTube のコメント機能を使うときだけ、YouTube からコメントを受け取ります）。
- 記録と設定は、解凍したフォルダの中の data フォルダに保存されます。このフォルダは人に渡さないでください。
